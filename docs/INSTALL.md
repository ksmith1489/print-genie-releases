# Installation and download safety

The first release package and its exact installation instructions are pending final validation. The intended initial target is 64-bit Windows 10 or 11. Download only from the official Releases page of this repository; verify the published SHA-256 checksum and the Windows publisher signature before running an installer. A checksum obtained from the same download page helps detect accidental corruption but does not independently prove who published a file.

Microsoft Edge WebView2 Runtime may be needed for the desktop window; the existing preview has a browser fallback. The app includes its Node runtime; users should not need a separate Node installation. Verify these requirements and installation, upgrade, removal, and the missing-WebView2 experience on clean Windows before publishing this page as final instructions.

Connect a supported network printer using its address in the app. External slicer or CAD tools and AI services are optional and may require separate installation, accounts, or payment. Keep a backup of your Personal ownership file and recovery information when moving computers.

Do not bypass a Windows security warning to install an unsigned or unexpected file. Contact support if a signature is missing, invalid, or identifies an unfamiliar publisher.
