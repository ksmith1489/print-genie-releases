# Proposed first GitHub release: Print Genie Community 0.13.22

**Draft for review.** The signed direct-download package and final release contents have not yet been approved for publication.

Print Genie Community brings together local printer management, guided workflows and failed-print recovery, with optional connected AI. The AI settings offer prepaid access, and Personal owners can use their own provider key or local models. Personal ownership is activated by importing the ownership file from the purchase page.

The planned Windows x64 distribution will include third-party notices and the matching GPL-licensed Blender bridge source. See the installation guide and checksum in the release when the final package is available.

A printer, network connection and compatible printer setup are needed for hardware functions. Optional AI and separate modeling or slicing tools may have their own requirements and costs. Actual support depends on the printer and available integrations.

Personal is a $29.99 one-time upgrade plus applicable taxes, with lifetime software upgrades. AI usage is separate. [Personal purchase and restore](https://3dprintsaver.com/personal).
